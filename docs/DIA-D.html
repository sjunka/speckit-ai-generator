specs/001-ai-media-generator/spec.md: "<HU literal del profesor>".
NO crees una feature nueva, NO corras scripts de nueva feature,
NO cambies de rama. Solo actualiza ese spec.md.
/speckit-tasks Agrega al final de tasks.md SOLO los tickets de la
User Story recién agregada, numerados desde T040. Máximo 3 tickets,
con listas Owns disjuntas entre sí. NO regeneres los existentes.
git add -A && git commit -m "HU en vivo: spec y tickets" && git push

2 · Los asignados construyen (~5 min, en paralelo)

Dos personas por HU, un ticket cada una, rama propia:

git checkout main && git pull origin main
git checkout -b hu-viva-t040
/speckit-implement T040
npm test
git add -A && git commit -m "T040" && git push -u origin hu-viva-t040

Cambia T040 por tu ticket. Si npm test sale rojo, no subas: muéstralo y pídele al agente que lo arregle — que el método atrape el error también es demo.

3 · Santiago cierra (~2 min)

git checkout main && git fetch origin
git merge origin/hu-viva-t040   # uno por uno, nunca juntos

npm test && git push origin main

El push a main despliega solo en Vercel. Abrir la URL de producción en el celular y mostrar la HU funcionando.
